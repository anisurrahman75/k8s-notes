# **1. Your First Mount Namespace**

## **Go**

```bash
unshare -Urm bash
```

You now have your own mount table — a **copy** of the host's at the moment of creation.

```bash
findmnt | wc -l
mount -t tmpfs -o size=16M tmpfs /mnt
df -h /mnt | tail -1
touch /mnt/only-inside
ls /mnt
```

```
66
tmpfs            16M     0   16M   0% /mnt
only-inside
```

Now, **from the host**:

```bash
ls /mnt
findmnt /mnt
```

```
(empty — and findmnt prints nothing)
```

The tmpfs does not exist outside. Mounting a filesystem — normally strictly root-only — worked because your mount namespace is *owned by* your user namespace ([../1.namespaces/2.user-namespace.md](../1.namespaces/2.user-namespace.md)).

## **Demo with a scratch path** (safer than `/mnt`)

```bash
S=/tmp/nslab; mkdir -p $S/mp

unshare -Urm bash -c "
  mount -t tmpfs -o size=16M tmpfs $S/mp
  df -h $S/mp | tail -1
  touch $S/mp/inside
  echo 'inside ns:  ' \$(ls $S/mp)
"
echo "host sees:   $(ls $S/mp)"
```

```
tmpfs            16M     0   16M   0% /tmp/nslab/mp
inside ns:   inside
host sees:
```

The file vanished with the namespace. Not deleted — the tmpfs it lived on was freed when the last member process exited ([../1.namespaces/4.lifetime-and-nesting.md](../1.namespaces/4.lifetime-and-nesting.md)).

## **What you can mount rootless**

In a user namespace, the kernel only permits filesystem types with no untrusted on-disk metadata:

| Allowed | Blocked |
| ------- | ------- |
| `tmpfs`, `ramfs` | `ext4`, `xfs`, `btrfs` (any block device) |
| `proc`, `sysfs`, `devpts`, `mqueue` | `nfs`, `cifs` |
| `cgroup2` | loop-mounted images |
| `overlay` (kernel 5.11+) | |
| `fuse` (kernel 4.18+) | |
| bind mounts of anything you can already read | |

```bash
unshare -Urm bash -c 'mount -t ext4 /dev/sda1 /mnt'
```

```
mount: /mnt: permission denied.
```

> 🔑 This restriction is *why* rootless containers use **overlayfs or fuse-overlayfs** for images and never a loopback ext4. See [4.overlayfs.md](4.overlayfs.md).

## **⚠️ You cannot unmount what you inherited**

Intuition says "I have my own table, so I'll unmount everything I don't want." In a **user namespace** that fails:

```bash
unshare -Urm bash -c 'umount /proc; echo "rc=$?"'
```

```
umount: /proc: not mounted.
rc=32
```

`/proc` is very much mounted. The kernel marks every mount **inherited** into an unprivileged mount namespace as `MNT_LOCKED` and refuses to unmount it — otherwise you could unmount a `ro` or `nosuid` mount to reveal whatever the admin had deliberately covered up. The confusing "not mounted" wording is `umount(8)` misreporting `EINVAL`.

**What you mounted yourself unmounts fine:**

```bash
unshare -Urm bash -c "mount -t tmpfs tmpfs $S/mp && echo mounted && umount $S/mp && echo 'umounted OK'"
```

```
mounted
umounted OK
```

> 🔑 **This is why containers use `pivot_root` instead of "unmount the host away".** You don't dismantle the inherited tree — you replace the root with your own and detach the old one wholesale. See [6.pivot-root.md](6.pivot-root.md).

## **Inspecting a mount table**

```bash
findmnt                                  # tree view — the readable one
findmnt -no SOURCE,TARGET,FSTYPE,OPTIONS /path
findmnt --target /some/file              # which mount backs this path
cat /proc/self/mounts                    # raw, what the process sees
cat /proc/self/mountinfo                 # raw + propagation + mount IDs
```

`mountinfo` is the authoritative one — it is the only place propagation state ([2.propagation.md](2.propagation.md)) is exposed:

```bash
head -3 /proc/self/mountinfo
```

```
28 32 0:25 / /proc rw,nosuid,nodev,noexec,relatime shared:13 - proc proc rw
│  │  │    │ │                                     │            │
│  │  │    │ │                                     │            └ fstype + source
│  │  │    │ │                                     └ propagation: shared, peer group 13
│  │  │    │ └ mount point
│  │  │    └ root of the mount within its filesystem
│  │  └ major:minor device
│  └ parent mount ID
└ mount ID
```

**Compare two namespaces:**

```bash
unshare -Urm bash -c 'sleep 60' &
sleep 1; P=$(pgrep -x sleep | tail -1)
diff <(cat /proc/self/mounts) <(sudo cat /proc/$P/mounts)
kill $P
```
